# Cordée Compagnon

Application web pour Android : photos et notes audio rangées dans Cordée, l'outil de projets d'Advanced Care Technologies.

Ce dépôt ne contient que l'application construite, servie par GitHub Pages. **Aucune donnée de l'équipe ici** : elles restent
chiffrées dans un dépôt privé, et le téléphone ne les lit qu'avec le code QR affiché par Cordée et le mot de passe de la personne.

Le code source est dans le dépôt privé de Cordée, dossier `companion/`.
